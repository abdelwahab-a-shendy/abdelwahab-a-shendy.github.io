# Connecting GitHub with Obsidian

Now I’ll explain how to connect Obsidian to GitHub step by step, so you can keep a backup of your Obsidian notes on GitHub, access them whenever you need, and share them with others if you want.

The process is simple and beginner-friendly, even if you have no previous experience with Git.

🛠️ Prerequisites:  
✅ A GitHub account

✅ A Git installation on your device

✅ An Obsidian folder (the Vault) is ready

✅I will use the simplest method, which is GitHub Desktop.

## **A small privacy tip:**

If you have personal or sensitive notes, make sure your GitHub repository is Private, or exclude those notes from Git using a `.gitignore` file.

Remember: A Private repository is not a substitute for keeping sensitive information out of cloud backups.
